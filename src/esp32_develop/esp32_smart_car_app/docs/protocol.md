# 移动监控智能小车通信协议

## 1. 概述
本协议基于 WebSocket 协议进行通信，数据格式采用 JSON。
默认 WebSocket 端口：80

## 1.1 控制算法架构
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐ 
│   指令输入   │────→│  运动学解算  │────→│  PID+前馈   │────→│   PWM输出   │ 
│ (Vx,Vy,ω)   │     │  麦科姆矩阵  │     │  编码器闭环  │     │  JGA-N20驱动 │ 
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘ 
                                                ↑ 
                                         ┌─────────────┐ 
                                         │  编码器反馈  │ 
                                         │ (AB相, 7PPR)│ 
                                         └─────────────┘ 
```

## 1.2 电机参数
| 参数         | 数值                       | 说明               | 
| :--------- | :----------------------- | :--------------- | 
| 额定转速       | 100 RPM = 10.47 rad/s    | 空载理论最大值          | 
| 减速比        | 1:150                    | 内部行星减速           | 
| 编码器分辨率     | 7 PPR × 4 = 28 CPR       | AB相四倍频           | 
| 输出轴分辨率     | 28 × 150 = **4200 CPR**  | 减速后每转脉冲          | 
| 100RPM对应频率 | 4200 × 100/60 = **7kHz** | 编码器最大频率          | 
| 轮径（假设60mm） | 周长 188.5mm               | 100RPM = 314mm/s |

## 2. 指令集 (App -> ESP32)

### 2.1 移动控制
控制小车全向移动。
- `vx`: 前后速度 (-1.0 ~ 1.0)
- `vy`: 左右平移速度 (-1.0 ~ 1.0)
- `vw`: 自转速度 (-1.0 ~ 1.0)

```json
{
  "cmd": "move",
  "vx": 0.5,
  "vy": 0,
  "vw": 0
}
```

### 2.2 舵机云台控制
控制两个舵机的角度。
- `channel`: 0 (水平/超声波), 1 (俯仰/摄像头)
- `angle`: 角度 (0 ~ 180)

```json
{
  "cmd": "servo",
  "channel": 0,
  "angle": 90
}
```

### 2.3 工作模式切换
- `mode`: "manual" (手动), "auto" (自动避障)

```json
{
  "cmd": "mode",
  "value": "auto"
}
```

### 2.4 最大速度设置
- `value`: 0 ~ 255

```json
{
  "cmd": "speed",
  "value": 200
}
```

## 3. 状态反馈 (ESP32 -> App)

### 3.1 实时传感器数据
周期性发送或按需发送。
- `dist`: 超声波检测距离 (cm)
- `mode`: 当前模式

```json
{
  "type": "status",
  "dist": 25.4,
  "mode": "manual"
}
```

## 4. 视频流 (ESP32-CAM)
视频流独立于控制通道，通常使用 HTTP MJPEG 协议。
- 地址格式: `http://robocar-cam.local:81/stream` (或 IP 形式)

## 5. 固件 OTA 更新

### 5.1 统一更新界面
- 地址: `http://<ESP32-S3-IP>/update` 或 `http://robocar-xxxxxx.local/update`
- 功能: 支持上传 `.bin` 固件，并选择更新对象（S3 主控或 CAM 视觉模块）。

### 5.2 直连更新 (调试用)
- ESP32-CAM 直连地址: `http://robocar-cam.local/update`
