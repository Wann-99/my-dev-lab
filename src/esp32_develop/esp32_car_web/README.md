# RoboCar-A 网页控制台

独立的浏览器版小车控制台，**无需手机、无需安装任何环境**，在电脑/平板浏览器中直接打开即可使用。

通过本地 WebSocket 直连 ESP32 小车，复用了与 Flutter App 完全一致的通信协议。

## 功能

- ✅ **麦克纳姆轮全向控制**：移动摇杆支持任意方向**平移**（含横向、斜向），不只是前后转向
- ✅ **原地旋转 + 编码器闭环一键掉头**：`左转/右转`（或 `Q/E`）原地旋转，`一键掉头` 由固件读编码器精确转 180°
- ✅ **速度可调**：滑块实时调速，直接设置固件电机最大速度（`speed` 指令）
- ✅ **摄像头视角调节**：`看近处 / 回中 / 看远处` 一键调整云台俯仰，看清小车附近地面
- ✅ **视频低延时**：相机画质/延时三档可切（流畅/均衡/清晰），降分辨率提压缩率，默认低延时
- ✅ **本地 WebSocket 控制**：灯光、喇叭、自动避障、急停
- ✅ **键盘操控**：`W/S` 前后，`A/D` 左右平移，`Q/E` 旋转，`方向键` 云台，`空格` 急停，`L` 灯，`H` 喇叭
- ✅ **实时遥测**：电池电量/电压、超声波距离、WiFi 信号、延迟、运行时长、MAC、固件版本
- ✅ **摄像头画面**：MJPEG 实时视频流 + 截图保存（带断流自动重连）
- ✅ **WiFi 配网**：扫描周边网络、为小车配置新 WiFi
- ✅ **OTA 固件升级**：上传主控 / 摄像头固件（见下方注意事项）
- ✅ **电压校准**：用万用表实测值标定显示电压
- ✅ **设备管理**：重启、恢复出厂设置

### 麦轮运动说明

固件运动学 `move_car(vx, vy, vw)`：`vx`=前后、`vy`=横向平移、`vw`=旋转，四轮独立解算。

- **平移**：拨动移动摇杆到任意方向即可（上下=前后，左右=横移，斜向=斜行）。
- **一键掉头（编码器闭环）**：网页发 `{"cmd":"turn","counts":N,"dir":1}`，由小车固件读编码器
  脉冲精确旋转到位再停，**不受电量/地面影响**。需要烧录 `esp32_car_firmware_encoder/` 里的固件。
  - **校准**：「设备管理 →掉头校准」点「测试掉头」，转过头就减小脉冲数、没转够就增大，调好后保存。
  - ⚠️ 若小车仍用旧固件（不认识 `turn` 指令），一键掉头不会动——请先烧录新固件。
- **视频延时**：相机右上角下拉切换「流畅·低延时 / 均衡 / 清晰」。延时高时选「流畅」。
  注意同一时间只让一个端看画面（ESP32-CAM 通常只允许 1 个观看者）。
- **摄像头看近处**：`看近处` 把云台下俯（tilt=70°）查看车前地面，`看远处` 抬头（tilt=10°）。
  若你的云台接线方向相反导致上下颠倒，对调这两个按钮的体感即可（或直接用云台摇杆微调）。

## 使用方法

### 方式一：直接打开（最简单）
双击 `index.html`，浏览器（Chrome / Edge / Safari）即可打开使用。

### 方式二：本地服务器（推荐，兼容性最好）
在本文件夹下运行任意静态服务器，例如：

```bash
# Python
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

连接步骤：
1. 让电脑与小车处于同一网络（或连接小车的 AP 热点）
2. 在「连接设置」中填写小车 IP（AP 直连模式默认 `192.168.4.1`）
3. 点击「连接」

## ⚠️ 浏览器限制说明

由于浏览器的安全策略，与原生 App 有以下区别：

| 项目 | 说明 |
|------|------|
| **必须用 http/file 打开** | 不能通过 `https://` 打开本页面，否则浏览器会拦截对小车的 `ws://` 和 `http://` 明文请求（混合内容限制）。 |
| **无 mDNS 自动发现** | 浏览器无法访问 mDNS，需**手动输入小车 IP**。 |
| **OTA 需要固件支持 CORS** | 网页发起的 OTA HTTP 请求是跨域请求。若小车固件的 Web 服务未返回 `Access-Control-Allow-Origin` 头，上传会被浏览器拦截。此时请改用手机 App 升级，或在固件中为 `/update`、`/upload`、`/finalize` 接口添加 CORS 响应头。 |
| **摄像头流跨域** | MJPEG 画面以 `<img>` 加载，正常显示不受影响；但「截图」功能在跨域时可能因画布污染失败。 |
| **不含 MQTT 远程模式** | 按需求仅实现本地直连。浏览器无法直连 TCP MQTT（1883），如需远程须用 MQTT-over-WebSocket。 |

## 通信协议（与固件约定）

- **连接**：`ws://<IP>:80/ws`
- **指令**（发送给小车，已与固件 `car_commands.c` 核对）：
  - `{"cmd":"move","vx":<-1..1>,"vy":<-1..1>,"vw":<-1..1>}`（vx 前后 / vy 平移 / vw 旋转）
  - `{"cmd":"turn","counts":<int>,"dir":1|-1}` 或 `{"cmd":"turn","angle":180,"dir":1}`（编码器闭环掉头，需新固件）
  - `{"cmd":"speed","value":<10..100>}`（固件 `max_speed = value*10`，上限 1023）
  - `{"cmd":"servo","channel":0|1,"angle":<int>}`（0=水平 0–180°，1=俯仰 0–70°）
  - `{"cmd":"light","val":0|1}` / `{"cmd":"horn","val":0|1}`
  - `{"cmd":"mode","value":"AUTO"|"MANUAL"}`（自动避障；固件读 `value` 字段）
  - `{"cmd":"status"}` / `{"cmd":"scan_wifi"}`
  - `{"cmd":"wifi_config","ssid":"","password":"","test":true}`
  - `{"cmd":"reboot"}` / `{"cmd":"factory_reset"}`
- **遥测**（小车返回）：`mac`、`bat`/`v_car`、`dist`、`rssi`、`ssid`、`version`、`cam_version`、`cam_ip`
- **摄像头**：`http://<camIP>:81/stream`
- **OTA**：`POST /update?target=main|camera&size=` → 分块 `POST /upload`（`X-Offset` 头）→ `POST /finalize`
